# Definição

_*Profiling*_ é o processo de medir o desempenho de diferentes partes de um programa para descobrir onde ocorrem atrasos (_bottlenecks_).

## Ferramentas em Python
- *cProfile* - Incorporado
- *line_profiler* - detalhado por linha
- *memory_profiler* - uso de memória

### Exemploe em _Bash_

`python -m cProfile myscript.py`
