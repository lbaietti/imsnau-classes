# nvitAPP
- Registo de participantes de um Evento

## Funcionalidades 
- Registo com nome, email e código postal
- Consulta de localidade via API
- Armazenamento local em JSON
- Interface simples em HTML + JS

## Como correr a app
1. Instalar dependências (`pip install flask requests`)
2. Executar com `python app.py`
