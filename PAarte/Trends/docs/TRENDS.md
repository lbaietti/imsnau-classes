# Programação reativa e orientada a eventos 

## Programação orientada a eventos
- Executa ações em resposta a eventos (ex: cliques, inputs, notificações)

## Programação reativa
- Modela fluxos de dados dinâmicas que propagam alterações automaticamente 

*Exemplos*
- Interfaces Web com React JS
- Aplicações com RxJS, ReactiveX, MobX

*Vantagens*
- Reduz complexidade com assinaturas e subscrições
- Permite UI's altamente dinâmicas e interativas

*Ilustração*
`button.onclick = () => alert("Botão clicado!") // Orientado à Eventos`
